# Data Science Projects

My data science learning journey — built with Python, Pandas, and Streamlit.

## Projects

### Project 1 — Titanic EDA
Explored the Titanic dataset to find survival patterns.
- Tools: Pandas, Matplotlib, Seaborn
- Key findings: Gender, class, and age all affected survival chances

### Project 2 — COVID-19 Dashboard
Interactive dashboard showing COVID trends for 218 countries.
- Tools: Streamlit, Plotly, Pandas
- Features: Country selector, cases chart, deaths chart, daily new cases chart
  
**To run:**
```bash
python -m streamlit run project2_covid.py
```
